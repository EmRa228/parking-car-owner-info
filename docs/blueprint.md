# **App Name**: Parking Car Owner Info

## Core Features:

- Search & Stats UI: Landing page with search filters (plate, color, model) and statistics on car data.
- Search Results Display: Display search results as a list of cards optimized for mobile view, showing car details (plate, color, model) and owner unit name. Phone number is hidden until explicitly requested.
- Call Functionality: Implement a 'Call Owner' button that initiates a call to the owner's phone number.
- Anonymous Data Submission: Form for users to submit new car data (plate, color, model, owner name, unit name, phone). Plate and Phone are required fields. Submission is anonymous.

## Style Guidelines:

- Primary color: Teal (#008080) for a modern and trustworthy feel.
- Secondary color: Light gray (#F0F0F0) for backgrounds and subtle contrasts.
- Accent: Orange (#FFA500) for call-to-action buttons and highlights.
- Clean and minimalist layout with a focus on mobile responsiveness.
- Use modern and simple icons for search filters and data display.
- Subtle animations and transitions to improve user experience.
